# Security Policy

## Supported versions

LitLink is actively developed and ships frequently. Security fixes always
land in the **latest release**. Please update to the current version before
reporting an issue — you can see the newest version and release notes in the
[changelog](https://litpads.app/litlink/changelog).

| Version        | Supported |
| -------------- | --------- |
| Latest release | ✅        |
| Older releases | ❌        |

## Reporting a vulnerability

Please report security issues **privately** — do not open a public GitHub
issue for a vulnerability.

Email **support@litpads.app** with:

- A description of the issue and its impact
- Steps to reproduce (a proof of concept if you have one)
- Your LitLink version and macOS version

LitLink is a solo indie project, so replies come from a real person (Marcel),
usually within a few days. We'll acknowledge your report, keep you posted on
the fix, and credit you once it's resolved if you'd like.

Thank you for helping keep LitLink and its users safe.
